# راهنمای مدیریت کاربران و استفاده

## حساب‌ها
- `npm run seed` سه حساب می‌سازد: `mana` (والد)، `sarina`، `saman` (کودک) و رمزها را یک‌بار چاپ می‌کند (یا با `SEED_MANA_PASSWORD` … تعیین کنید).
- تغییر رمز مانا: **تنظیمات ← تغییر رمز**. تغییر رمز کودک: **خانواده ← انتخاب کودک ← اعلان‌ها و تنظیمات ← رمز عبور** (نشست‌های قبلی بسته می‌شود).
- **وحید** (`vahid`): حساب بزرگسال بدون هیچ دسترسی ساخته می‌شود. مانا از **تنظیمات ← حساب‌ها و دسترسی‌ها** برای هر بخش «بدون دسترسی / فقط مشاهده / مشاهده و ویرایش» تعیین می‌کند، رمز می‌دهد یا حساب را غیرفعال می‌کند. روی سرور موجود: `docker compose exec mana npx tsx scripts/add-member.ts vahid "وحید"` (رمز اولیه یک‌بار چاپ می‌شود).
- افزودن کاربر جدید فعلاً از طریق SQL/اسکریپت است (UI ندارد): ردیف `users` + `child_settings` (برای کودک).
- قفل شدن ورود (۵ اشتباه): ۱۰ دقیقه صبر کنید یا رمز را از حساب مانا عوض کنید.

## امکانات مرحله‌ی ۲
- **دانستنی‌ها و جمله‌ها:** تنظیمات ← «دانستنی‌ها و درس‌های سواد مالی» و «جمله‌های انگیزشی» (افزودن، غیرفعال، حذف).
- **کتابخانه:** «کتابخانه» ← بارگذاری PDF یا صوت؛ «چه کسی ببیند» را انتخاب کنید.
- **آشپزی:** «آشپزی» ← دسته‌ی جدید، دستور با عکس/ویدیو/لینک.
- **مالی بچه‌ها:** خانواده ← مالی و پول‌توجیبی: واریز، پول‌توجیبی هفتگی، هدف پس‌انداز.
- **AI بچه‌ها:** خانواده ← گفتگوهای AI: خاموش/روشن، سقف روزانه، مرور گفتگوها و موارد ⚠️. نیازمند `ANTHROPIC_API_KEY` در `.env` سرور.
- **امنیت:** تنظیمات ← حساب‌ها، تأیید دومرحله‌ای، پشتیبان‌گیری.

## دفترچه، پیام مامان، چت، آرزوها، مرور شبانه
- **پیام‌ها** (منوی «پیام‌ها»): برای یک یا چند نفر بنویسید؛ بچه با اعلان و در کاشی «پیام مامان» می‌خواند یا می‌شنود.
- **مرور و دفترچه** (خانواده ← کودک ← «🌙 مرور و دفترچه»): سؤال‌های شبانه را ویرایش کنید، ساعت و پاداش را تعیین کنید و نوشته‌های بچه را بخوانید (فقط‌خواندنی).
- **آرزوها**: بچه‌ها خودشان آرزو با عکس می‌گذارند و «رسیدم ✓» می‌زنند؛ شما اعلان می‌گیرید.
- **گزارش** (منوی «گزارش»): خلاصه‌ی هفته؛ جمعه‌ها اعلان می‌آید.
- **دسترسی هر نفر**: تنظیمات ← حساب‌ها و دسترسی‌ها ← ویژگی‌های شخصی (دفترچه، پیام، چت، آرزو، عکس) برای هر نفر جدا.
- **صدا**: تنظیمات (یا «🔊 تنظیم صدا» در صفحه‌ی بچه): سرعت (خیلی آرام/آرام/معمولی)، انتخاب صدای فارسی و انگلیسی، زبان میکروفون.
- **برنامه‌ی نمونه**: خانواده ← برنامه ← «📥 بارگذاری برنامه‌ی نمونه».

## ربات بله / تلگرام
۱) در بله با @botfather گفتگو کنید، `/newbot` بزنید و توکن را بگیرید (تلگرام هم همین‌طور). ۲) توکن را در `.env` سرور (یا `accounts.env` برای اجرای محلی) بگذارید: `BALE_BOT_TOKEN=…` و `MESSENGER_PROVIDERS=bale` (برای تلگرام: `telegram`، برای هر دو: `bale,telegram`) و سرور را راه‌اندازی مجدد کنید. ۳) تنظیمات ← «اتصال به بله / تلگرام» ← دریافت کد ← در ربات بنویسید `/start کد`. حالا اعلان‌ها در پیام‌رسان هم می‌آیند و `/today`، `/list`، `/add شیر` کار می‌کند.

## پشتیبان‌گیری
تنظیمات ← پشتیبان‌گیری: بازه‌ی ساعتی (پیش‌فرض ۲۴) و تعداد نگهداری. اگر از آخرین نسخه چیزی تغییر نکرده باشد نسخه‌ی تکراری ساخته نمی‌شود.

## هر روز
1. **داشبورد**: برنامه‌ی امروز، عقب‌افتاده‌ها، جلسات، سررسید اقساط، تأییدهای در انتظار.
2. **خانواده ← تأییدها**: انجام فعالیت‌های کودکان را تأیید کنید تا ستاره ثبت شود؛ درخواست جایزه‌ها را بررسی کنید.
3. **MANA AI** (یا دکمه‌ی ثابت «دستیار من 🎙️»): «فردا ساعت ۱۰ جلسه دارم» → پیشنهاد → «تأیید و ثبت».

## تنظیم برنامه‌ی کودکان
**خانواده ← برنامه ← ＋ فعالیت**: روزهای هفته یا یک تاریخ، ساعت (برای اعلان ضروری است)، ستاره، متن اعلان اختصاصی، آفست‌های یادآوری (مثل `-15,0,10`). برنامه‌ی نمونه‌ی seed (ساعت‌های مطالعه/سنتور/تکالیف) **فرضی** است و باید اصلاح شود؛ «شاهنامه‌خوانی» ساعت ندارد (در ورودی شما نبود) پس اعلان نمی‌دهد تا ساعت بگذارید.

## تصاویر
**خانواده ← تصاویر ← بارگذاری** (JPEG/PNG/WebP، تا ۸MB). «پروفایل» عکس را آواتار می‌کند. تصاویر فقط برای همان کودک و شما قابل دیدن‌اند.

## فعال‌سازی اعلان و صدا روی هر دستگاه
1. سایت را با **HTTPS** باز کنید و به صفحه‌ی اصلی اضافه کنید (Chrome ← Install).
2. روی همان دستگاه وارد حساب شوید و «روشن کردن اعلان روی این دستگاه» را بزنید و اجازه بدهید (برای کودک: روی صفحه‌ی خانه‌ی او).
3. صدا: «آزمایش صدا» را بزنید. اگر نشنیدید، در تنظیمات گوشی ← مدیریت زبان/خروجی تبدیل متن به گفتار، **فارسی** را فعال کنید.
4. میکروفون فقط با دکمه‌ی «بزن و حرف بزن» و با اجازه‌ی شما؛ از «اعلان‌ها و تنظیمات» می‌توانید آن را برای هر کودک خاموش کنید.
