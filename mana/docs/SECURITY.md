# امنیت

| کنترل | پیاده‌سازی | آزمون |
|---|---|---|
| احراز هویت | نام کاربری+رمز؛ scrypt (N=16384) با salt؛ نشست تصادفی ۲۵۶ بیتی، فقط SHA-256 آن در DB؛ کوکی HttpOnly + SameSite=Strict (+Secure در production)؛ انقضای ۱۴ روز | ✔ |
| قفل ورود | ۵ تلاش ناموفق → قفل ۱۰ دقیقه؛ محدودیت نرخ ۱۰/دقیقه روی ورود | ✔ |
| مجوز Backend | `requireParent/requireUser` روی هر مسیر؛ مسیرهای والد برای کودک ۴۰۳ | ✔ |
| مجوز Database | RLS روی ۲۵ جدول؛ نقش `mana_app` بدون BYPASSRLS؛ کودک حتی با SQL مستقیم نمی‌تواند داده‌ی مالی/کاری/خواهر-برادر را ببیند یا ستاره اضافه کند؛ `sessions` برای نقش برنامه قابل دسترس نیست | ✔ |
| نقش عضو بزرگسال | دسترسی ماژولی ۰/۱/۲ در API و RLS (`app_perm`)؛ خودافزایی دسترسی ناممکن؛ همه‌ی تغییرات در `audit_log` | ✔ |
| قفل ورود پیشرونده | هر ۵ شکست پیاپی: ۱۰ دقیقه قفل، سپس ۲۰، ۴۰، … تا ۲۴ ساعت؛ حتی رمز درست در زمان قفل رد می‌شود. این برای رمزهای کوتاه (مثل PIN چهاررقمی بچه‌ها) لازم است | ✔ |
| CSRF | SameSite=Strict + هدر اجباری `X-Requested-With: mana` روی درخواست‌های تغییردهنده | ✔ |
| اعتبارسنجی ورودی | Zod `strict()` روی همه‌ی بدنه‌ها؛ پارامتر SQL؛ نام ستون‌ها فقط از schema | ✔ |
| فایل‌ها | بررسی magic bytes (JPEG/PNG/WebP)، ≤ ۸MB، نام تصادفی، پوشه‌ی ۰۷۰۰؛ سرو فقط از مسیر دارای مجوز RLS با `nosniff`؛ حذف فایل هنگام حذف ردیف | ✔ |
| هدرها | Helmet + CSP محدود (`default-src 'self'`)، HSTS در production | ✔ (هدر) |
| اسرار | فقط در `.env`/محیط؛ کلید Claude هرگز به مرورگر نمی‌رود | — |
| حریم خصوصی صدا | MANA صدا ضبط/ذخیره نمی‌کند؛ میکروفون فقط با لمس دکمه؛ مانا می‌تواند `mic_allowed` را برای هر کودک خاموش کند. **توجه:** در Chrome/Android تشخیص گفتار توسط سرویس مرورگر (Google) انجام می‌شود | — |
| پشتیبان‌گیری | `server/scripts/backup.sh` (pg_dump + عکس‌ها)؛ زمان‌بندی و رمزنگاری با شما | زمان‌بندی نشده |

**ریسک‌های باقیمانده:** ۱) رمزها در seed تصادفی‌اند ولی باید تغییر کنند؛ ۲) ۲FA وجود ندارد؛ ۳) ردیابی لاگ دسترسی فقط برای تأیید‌های AI (`audit_log`)؛ ۴) نیاز به HTTPS در استقرار.

**رمزهای کوتاه:** مانا می‌تواند برای کودکان و عضو بزرگسال رمز ≥۴ نویسه بگذارد؛ این با قفل پیشرونده امن‌تر می‌شود ولی رمز بلندتر همیشه بهتر است — به‌ویژه برای وحید اگر به مالی/اقساط دسترسی بگیرد. حساب‌های مدیر (`mana`، `admin`) حداقل ۸ نویسه و ترجیحاً با تأیید دومرحله‌ای.
**ربات پیام‌رسان:** اتصال فقط با کد یک‌بارمصرف ۱۰ دقیقه‌ای که کاربرِ واردشده در برنامه می‌گیرد؛ گفتگوی متصل‌نشده هیچ داده‌ای نمی‌بیند؛ کودکان کد اتصال نمی‌گیرند؛ توکن ربات فقط در `.env`.
