۱. مرور کلی و حساب‌ها

MANA یک برنامه‌ی فارسی (RTL) و قابل نصب روی گوشی (PWA) است: پنل مدیریت مانا، حساب مستقل سارینا و سامان با دستیار صوتی و اعلان، و حساب وحید با دسترسی‌هایی که مانا تعیین می‌کند. پایگاه داده PostgreSQL است و محدودیت دسترسی هم در سرور و هم در خود پایگاه داده اجرا می‌شود.

نام کاربرینقشچه می‌بیند
manaمدیرهمه‌چیز؛ تنها کسی که دسترسی‌ها، رمز بچه‌ها و MANA AI را مدیریت می‌کند
adminمدیر (پشتیبان)دسترسی کامل مانند مانا؛ برای مواقع ضروری. رمز بلند و ترجیحاً با تأیید دومرحله‌ای
vahidبزرگسالپیش‌فرض: هیچ‌چیز. مانا برای هر بخش تعیین می‌کند
sarinaکودکفقط برنامه، ستاره، جوایز، عکس‌های خودش
samanکودکفقط مال خودش؛ رابط تصویری و صوتی
رمزهای اولیه: فایل جداگانه‌ی accounts.env رمزهایی را که تعیین کردید دارد. آن را کنار start-local.bat (پوشه‌ی deploy) بگذارید؛ در PDF و Git رمزی نوشته نشده است. رمزهای چهاررقمی (وحید، سارینا، سامان) کوتاه‌اند؛ سامانه با قفل پیشرونده (۱۰ دقیقه، ۲۰، ۴۰ … تا ۲۴ ساعت) از حدس‌زدن محافظت می‌کند ولی روی سرور اینترنتی رمز بلندتر، به‌ویژه برای وحید، توصیه می‌شود.

۳. اجرای کامل روی لپ‌تاپ

مرورگر آدرس http://localhost:8080 را «امن» می‌داند؛ پس نصب PWA، میکروفون و اعلان درون‌برنامه‌ای روی خود لپ‌تاپ قابل آزمایش است.

  1. نصب Docker Desktop از docker.com. بعد از نصب یک‌بار ویندوز را ریستارت کنید و صبر کنید آیکون Docker «Running» شود (اگر خواست، WSL 2 را فعال کنید).
  2. پوشه‌ی D:\Claude Project\MANA\deploy را باز کنید.
  3. روی start-local.bat دوبار کلیک کنید. بار اول چند دقیقه طول می‌کشد (ساخت برنامه و پایگاه داده).
  4. در پایان، رمز حساب‌ها چاپ می‌شود. همان‌جا یادداشت کنید؛ فقط یک‌بار نشان داده می‌شود.
  5. مرورگر http://localhost:8080 را باز می‌کند. با mana وارد شوید.
برای آزمون حساب بچه‌ها از یک پنجره‌ی Incognito یا مرورگر دوم استفاده کنید تا نشست مانا نپرد.

روشن/خاموش کردن

cd "D:\Claude Project\MANA\deploy"
docker compose -f docker-compose.local.yml down        # خاموش (داده‌ها می‌مانند)
docker compose -f docker-compose.local.yml up -d       # روشن دوباره
docker compose -f docker-compose.local.yml logs -f mana  # مشاهده‌ی لاگ
فایل‌های اجرای محلی در محیط ساخت آزمایش نشده‌اند (Docker آنجا نبود). اگر خطا دیدید، متن خطا را برای اصلاح بفرستید.

۵. تعریف دسترسی وحید

  1. با mana وارد شوید ← تنظیمات ← حساب‌ها و دسترسی‌ها.
  2. برای هر بخش یکی را انتخاب کنید: بدون دسترسی / فقط مشاهده / مشاهده و ویرایش.
  3. بخش‌ها: کارها و پروژه‌ها، تقویم، مالی (حساس)، اهداف و عادت‌ها، برنامه و پاداش کودکان، تصاویر کودکان.
  4. در همین‌جا می‌توانید رمز او را عوض کنید یا حسابش را غیرفعال کنید (فوراً خارج می‌شود).
وحید نمی‌تواند دسترسی خودش را بالا ببرد. MANA AI، مدیریت حساب‌ها و رمز بچه‌ها همیشه فقط برای مانا است. هر تغییر دسترسی در سابقه‌ی سیستم ثبت می‌شود.

۶. خرید دامنه و سرور، و استقرار آنلاین

این مرحله را بعد از پایان آزمون انجام دهید. اعلان وقتی برنامه بسته است، نصب روی گوشی و میکروفون روی گوشی فقط روی آدرس https:// کار می‌کنند.

۶-۱ خرید (یک‌بار)

  • دامنه (مثلاً bk-family.com)، حدود ۱۰ تا ۱۵ دلار در سال، از Namecheap، Porkbun یا مشابه.
  • سرور مجازی (VPS): اوبونتو ۲۴.۰۴، حداقل ۲ گیگ رم و ۲۰ گیگ دیسک (Hetzner، DigitalOcean، Contabo). مکان: اروپا.
  • در DNS دامنه یک رکورد A بسازید: نام @ ← آی‌پی سرور (تا ۳۰ دقیقه طول می‌کشد).

۶-۲ آماده‌سازی سرور

از PowerShell: ssh root@IP_SERVER و سپس:

apt update && apt install -y git docker.io docker-compose-v2
git clone -b ccr-e1b3dc84-iv05g9 https://github.com/manamoghadam-coder/Sarina-Earth-Animation.git
cd Sarina-Earth-Animation/mana/deploy

مخزن خصوصی است؛ هنگام clone نام کاربری GitHub و یک Personal Access Token با دسترسی خواندن می‌خواهد.

۶-۳ اسرار

cp env.example .env
openssl rand -base64 24      # سه بار: PG_ADMIN_PASSWORD, OWNER_DB_PASSWORD, APP_DB_PASSWORD
docker run --rm node:22-slim npx -y web-push generate-vapid-keys   # کلیدهای اعلان
nano .env                    # DOMAIN، رمزها، VAPID_*، VAPID_SUBJECT=mailto:ایمیل-شما
فایل .env را به هیچ‌کس ندهید و رمزها را در چت ننویسید.

۶-۴ اجرا

docker compose up -d --build
docker compose logs -f mana      # باید «MANA listening on :8080» ببینید (Ctrl+C)
docker compose exec mana npx tsx scripts/seed.ts   # ساخت حساب‌ها؛ رمزها را یادداشت کنید

حالا https://دامنه‌ی-شما باید صفحه‌ی ورود با لوگوی خانوادگی را نشان دهد. گواهی HTTPS را Caddy خودکار می‌گیرد.

بعد از استقرار: داده‌ی «نمونه» را حذف و رمزها را عوض کنید. به‌روزرسانی: git pull && docker compose up -d --build.

۷. نصب روی سه گوشی

اندروید (Chrome)

  1. آدرس سایت را در Chrome باز کنید.
  2. با حساب همان فرد وارد شوید: گوشی مانا ← mana، وحید ← vahid، سارینا ← sarina، سامان ← saman.
  3. منوی ⋮ ← Install app (افزودن به صفحه‌ی اصلی).
  4. از روی آیکون برنامه را باز کنید؛ روشن کردن اعلان روی این دستگاه را بزنید و Allow کنید.
  5. تنظیمات گوشی ← Apps ← Chrome ← Battery ← Unrestricted.

آیفون

iOS ۱۶.۴ یا بالاتر؛ فقط با Safari ← Share ← Add to Home Screen و باز کردن از آیکون. تشخیص گفتار فارسی روی آیفون محدودتر است.

رمز هر کودک را از «خانواده ← انتخاب کودک ← اعلان‌ها و تنظیمات ← رمز عبور» می‌توانید ساده‌تر (حداقل ۸ نویسه) کنید.

۸. صدا، میکروفون و اعلان‌ها

صدای فارسی

تنظیمات گوشی ← Google ← Text-to-speech output ← موتور Google ← زبان فارسی و دانلود داده‌ی صدا. در MANA «🔈 آزمایش صدا» را بزنید. اگر صدایی نیامد، برنامه بنر خطا نشان می‌دهد.

سه قابلیت اصلی حساب سامان

قابلیتطرز استفاده
شنیدن با لمس آیکونروی هر کاشی بزنید یا دکمه‌ی 🔊 کوچک آن؛ نام و کاربرد خوانده می‌شود
صحبت با دستیاردکمه‌ی ثابت «دستیار من 🎙️» پایین صفحه ← «بزن و حرف بزن». نمونه: «برنامه امروز من چیه؟»، «الان باید چیکار کنم؟»، «تکالیفم رو انجام دادم»، «قصه برام بخون»، «چند تا ستاره دارم؟». ثبت تغییر فقط پس از پاسخ «بله»
یادآوری صوتیاعلان فعالیت با صدا خوانده می‌شود (وقتی برنامه باز است). وقتی بسته است، اعلان پوش با صدای خود گوشی می‌آید

«🔊 برایم بخوان» در هر صفحه محتوا را به‌ترتیب می‌خواند؛ توقف، ادامه، تکرار و سرعت دارد. اگر مرورگر تشخیص گفتار ندارد، دکمه‌های تصویری و تایپ جایگزین‌اند.

حریم خصوصی: MANA صدا ضبط یا ذخیره نمی‌کند و میکروفون فقط با لمس دکمه روشن می‌شود. در Chrome اندروید، تشخیص گفتار توسط سرویس Google انجام می‌شود. مانا می‌تواند میکروفون را برای هر کودک خاموش کند.

اعلان‌ها

  • تعریف در «خانواده ← برنامه»: ساعت شروع، متن اختصاصی، آفست‌ها (مثل -15,0,10: ۱۵ دقیقه قبل، شروع، ۱۰ دقیقه بعد اگر انجام نشده).
  • «خانواده ← اعلان‌ها و تنظیمات»: فعال/غیرفعال، ساعت سکوت، تاریخچه، ارسال اعلان آزمایشی.
  • وضعیت ارسال در تاریخچه: sent:1 = پوش رفت؛ no_subscription = روی آن گوشی اعلان روشن نشده؛ no_vapid_keys = کلیدها در .env نیست.

۸-۱. امکانات تکمیلی

بخشمسیر در برنامهتوضیح

عادت‌ها و داروخانواده ← عادت‌ها و داروهر مورد دلخواه (مسواک، روتین پوستی، شربت تقویتی…) با چند ساعت یادآوری؛ دارو در ساعت سکوت هم اعلان می‌دهد.
درخواست خرید و پیشنهادبچه‌ها: «درخواست خرید»، «پیشنهاد من»؛ مانا: خانواده ← درخواست‌هادسته‌ها: تغذیه مدرسه، لباس، وسایل مدرسه، کلاس/ثبت‌نام؛ وضعیت: در انتظار، تأیید، خریده شد، رد.

کتابخانهمانا: «کتابخانه»؛ بچه‌ها: «کتابخانه»بارگذاری PDF (تا ۴۰MB) و قصه‌ی صوتی (تا ۱۵۰MB)؛ هر کودک فقط موارد «همه» یا گروه سنی خودش را می‌بیند.
آشپزی«آشپزی»دسته‌ها (سنتی، فست‌فود، ساندویچ، دسر، سالاد، …) قابل افزودن؛ هر دستور با عکس، ویدیو (آپلود تا ۲۵۰MB یا لینک)، مواد و طرز تهیه.
AI بچه‌هابچه‌ها: «از دستیار بپرس» یا دکمه‌ی «دستیار من»؛ مانا: خانواده ← گفتگوهای AIپاسخ ساده و مناسب سن، با صدا؛ همه‌ی گفتگوها برای مانا ثبت می‌شود؛ موضوع‌های حساس به مدل نمی‌رسند و ⚠️ می‌خورند؛ سقف روزانه و خاموش/روشن. نیازمند کلید API در .env سرور.
دسترسی‌هاتنظیمات ← حساب‌ها و دسترسی‌هابرای وحید یا هر بزرگسال: مالی، بدهی و اقساط، کارها، تقویم، اهداف، کودکان، تصاویر، کتابخانه، آشپزی — هرکدام جدا.

لیست خرید مشترک«خرید»؛ مانا: خانواده ← درخواست‌ها ← «قبول و افزودن به لیست»دسته‌بندی (خوراکی، خانه، مدرسه، سلامت)، تیک «خریده شد»، پاک‌کردن خریده‌شده‌ها. دسترسی جدا برای هر نفر.
سلامت«سلامت»واکسن، قرار پزشک، چکاپ، دندان‌پزشک برای هر فرد؛ یادآوری شب قبل و صبح همان روز. فقط ثبت و یادآوری است، توصیه‌ی پزشکی نمی‌دهد.
پیوست فایل برای کارهاکارها ← ویرایش کارPDF، عکس، Word/Excel/PowerPoint تا ۲۵ مگابایت.
ربات بله / تلگرامتنظیمات ← اتصال به بله / تلگراماعلان‌ها در پیام‌رسان هم می‌آید؛ دستورهای /today /list /add. بله پیش‌فرض؛ تعویض یا فعال‌کردن تلگرام فقط با تغییر MESSENGER_PROVIDERS.
پشتیبان بدون تکرارتنظیمات ← پشتیبان‌گیریبازه‌ی ساعتی قابل تنظیم؛ اگر داده تغییر نکرده، نسخه‌ی تکراری ساخته نمی‌شود؛ پایگاه داده و فایل‌ها جدا بررسی می‌شوند.
گزارش هفتگیاعلان جمعه ساعت ۱۸ستاره‌ها و عادت‌های بچه‌ها، کارها، درخواست‌های منتظر، هزینه‌ی هفته.

راه‌اندازی ربات بله (و تلگرام)

  1. در بله با @botfather گفتگو کنید، /newbot بزنید و نام بدهید؛ توکن را بگیرید. (تلگرام: همان کار با @BotFather)
  2. توکن را در .env سرور (یا accounts.env برای اجرای محلی) بنویسید: 
    MESSENGER_PROVIDERS=bale
BALE_BOT_TOKEN=توکن-شما
# برای تلگرام: MESSENGER_PROVIDERS=telegram و TELEGRAM_BOT_TOKEN=…  ؛ برای هر دو: bale,telegram
  3. برنامه را دوباره راه‌اندازی کنید. در تنظیمات «دریافت کد اتصال» را بزنید و در ربات بنویسید /start کد.
نشانی API بله به‌صورت پیش‌فرض https://tapi.bale.ai است (از مستندات حافظه‌ام؛ در این محیط نتوانستم با سرویس واقعی بسنجم). اگر اتصال برقرار نشد، نشانی درست را از مستندات رسمی بله بگیرید و با BALE_API_BASE تنظیم کنید.
کلید AI: از console.anthropic.com کلید API بگیرید، در فایل .env سرور مقدار ANTHROPIC_API_KEY را بنویسید و سقف هزینه‌ی ماهانه را در همان پنل تعیین کنید. بدون کلید، بخش «از دستیار بپرس» پیام «هنوز فعال نشده» می‌دهد.

۹. کارهای روزمره و نگهداری

  • هر روز: داشبورد ← تأیید فعالیت‌های بچه‌ها در «خانواده ← تأییدها» ← MANA AI برای ثبت سریع.
  • برنامه‌ی بچه‌ها: ساعت‌های نمونه‌ی مطالعه، سنتور، تکالیف و زبان فرضی‌اند و باید اصلاح شوند. «شاهنامه‌خوانی» ساعت ندارد و تا ساعت نگذارید اعلان نمی‌دهد.
  • پشتیبان: هر شب ساعت ۳ خودکار (۷ نسخه‌ی آخر)؛ از تنظیمات دانلود کنید و گاهی بیرون از سرور نگه دارید. بازیابی با pg_restore.
  • افزودن حساب بزرگسال دیگر: docker compose exec mana npx tsx scripts/add-member.ts نام‌کاربری "نام"
  • قفل ورود: بعد از ۵ رمز اشتباه، ۱۰ دقیقه قفل می‌شود.

۱۱. محدودیت‌ها و موارد آزمون‌نشده

  • آزمون‌شده در محیط ساخت: ۲۹ تست خودکار امنیت/دسترسی/ستاره/مالی/کتابخانه/آشپزی/AI/اعلان/پشتیبان بدون تکرار/پیام‌رسان/لیست خرید/سلامت/پیوست و سناریوی مرورگر (موبایل، تبلت، دسکتاپ) با گفتار شبیه‌سازی‌شده.
  • آزمون‌نشده: اجرای Docker (محلی و سرور)، اعلان پوش واقعی، صدای/تشخیص گفتار واقعی روی گوشی اندروید، پاسخ AI بچه‌ها با کلید واقعی (با سرور شبیه‌ساز آزموده شد)، نمایش PDF داخل برنامه‌ی نصب‌شده روی گوشی.
  • ساخته‌نشده: مناسبت‌های قمری (عمداً)؛ آمار پیشرفته.
  • آزمون‌نشده: اتصال واقعی به API بله/تلگرام.
  • حالت کودکانه بر اساس «گروه سنی» حساب تعیین می‌شود.
  • برای دسترسی «فقط مشاهده»، دکمه‌های افزودن پنهان نمی‌شوند؛ بنر نشان داده می‌شود و سرور نوشتن را رد می‌کند.
