# سفر به ساختمان درونی زمین — انیمیشن آموزشی (پایه ششم)

انیمیشن کارتونی ۶۰ ثانیه‌ای با راهنمای فضانورد، گویندگی فارسی، زیرنویس هم‌زمان و نام «سارینا کریمی» ثابت در گوشه‌ی بالا-راست همه‌ی فریم‌ها.

## خروجی‌ها (پوشه‌ی `output/`)
| فایل | توضیح |
|---|---|
| `Sarina_Earth_Interior_Journey.mp4` | ویدئوی نهایی، 1920×1080، 16:9، ۳۰ فریم/ثانیه، H.264 + AAC، زیرنویس سوخته‌شده با FFmpeg |
| `subtitles_fa.srt` | زیرنویس فارسی (۱۳ تکه، هم‌زمان با گفتار) |
| `narration_fa.wav` | فقط صدای گویندگی (مصنوعی فارسی) |
| `soundtrack_full_mix.mp3` | میکس کامل صدا (گویندگی + موسیقی + جلوه‌ها) |

## ساختار صحنه‌ها
| ثانیه | صحنه | تصویر |
|---|---|---|
| ۰–۸ | معرفی | زمین سه‌بعدی در حال چرخش، ستاره‌ها، ماه، عنوان، فضانورد در حال سلام |
| ۸–۱۸ | برش عرضی | باز شدن برش گوه‌ای واقعی (Ray-casting)، چهار لایه با برچسب و خط راهنما به ترتیب گفتار |
| ۱۸–۳۳ | پوسته و گوشته | فرود از سطح (خانه/درخت) به پوسته‌ی لایه‌لایه و سپس گوشته با حباب‌های ماگما و پیکان‌های جریان همرفتی |
| ۳۳–۴۵ | هسته خارجی | گردابِ فلز مایع نارنجی/زرد، قطره‌های «آهن» و «نیکل» |
| ۴۵–۵۴ | هسته داخلی | کره‌ی طلایی جامد با وجوه بلورین، نشان‌های «داغ» و «جامد» |
| ۵۴–۶۰ | جمع‌بندی | برش کامل با چهار نام، متن پایانی و کاغذ‌پاره‌های رنگی |

## نکات علمی
- ترتیب از بیرون به مرکز: پوسته ← گوشته ← هسته خارجی (مایع) ← هسته داخلی (جامد).
- ضخامت لایه‌ها **شماتیک** است (شعاع‌های نسبی ۰٫۸۹ / ۰٫۵۷ / ۰٫۳۰)، نه مقیاس واقعی (در واقعیت پوسته بسیار نازک‌تر است).

## نتیجه‌ی کنترل کیفیت (`python3 src/qa_check.py` — همه موفق)
- مدت ۶۰٫۰۰۰ ثانیه، 1920×1080، ۱۸۰۰ فریم، H.264/AAC.
- متن هر ۶ صحنه، عنوان و متن پایانی دقیقاً مطابق سناریو؛ بدون حروف لاتین ناخواسته.
- هم‌زمانی SRT با گفتار: آغاز زیرنویس ۰ تا ۳۷ms زودتر از گفتار، پایان ۶ تا ۸۵ms بعد از آن؛ صدای MP4 با فایل گویندگی ۰ms اختلاف.
- «سارینا کریمی» در هر ۱۸۰۰ فریم، با موقعیت ثابت (x=1637، y=14) و حداقل ۹۴٪ پیکسل‌های حروف سفید.
- زیرنویس‌ها داخل محدوده‌ی امن ۵٪ (x:394–1526، y:904–953).

## بازتولید
```bash
bash run_all.sh          # صدا → موسیقی → رندر → مونتاژ → کنترل کیفیت
```
اجزا: `src/make_voice.py` (Piper `fa_IR-amir` + SRT)، `src/make_audio.py` (موسیقی و جلوه‌ها با کد)، `src/anim/` (رندرر: زمین سه‌بعدی `earth.py`، صحنه‌ها `scene_*.py`، فضانورد `sprites.py`)، `src/render_video.py`، `src/assemble.sh`، `src/qa_check.py`. متن/زمان‌بندی در `src/script_data.py`.
مدل صدا (۷۹MB) در گیت نیست؛ `run_all.sh` آن را دانلود می‌کند.

## محدودیت‌ها و فرض‌ها (صادقانه)
- گویندگی با **صدای مصنوعی مردانه** (Piper) ساخته شده؛ تلفظ برخی واژه‌های محاوره‌ای («زمینه»، «می‌دونیم») باید با گوش کنترل شود. برای صدای انسانی، `build/narration.wav` را جایگزین و `make_audio.py` و `assemble.sh` را اجرا کنید.
- «سه‌بعدی» با رندرر نرم‌افزاری اختصاصی (سایه‌ی Toon، برش تحلیلی کره) ساخته شده، نه نرم‌افزار انیمیشن مانند Blender.
- زمان نمایش برچسب‌های کلمات (پوسته، گوشته، آهن، نیکل…) از روی انرژی صدا **تخمین** زده شده (دقت ~۰٫۱–۰٫۲ ثانیه)؛ زمان زیرنویس‌ها دقیق‌اند.
- فضانورد راهنما، طبق پیشنهاد، اضافه شده است (بدون هیچ متن روی تصویر).
