# CRM فارسی — سیستم مدیریت ارتباط با مشتری

سیستم کامل CRM با رابط راست‌به‌چپ فارسی، تقویم شمسی و **بدون هیچ وابستگی خارجی** (فقط Node.js ≥ 22.13؛ پایگاه‌داده SQLite داخلی Node).

## اجرا
```bash
cd crm
npm start                 # http://127.0.0.1:3000
npm run seed              # (اختیاری) داده‌ی نمونه؛ گذرواژه‌ی کاربران دمو: Demo12345
npm test                  # تست‌های API و تقویم شمسی
```
در اولین اجرا کاربر `admin` ساخته می‌شود و گذرواژه‌ی تصادفی‌اش **یک‌بار در کنسول** چاپ می‌شود (یا با `CRM_ADMIN_PASSWORD` تعیین کنید).

متغیرهای محیطی: `PORT`، `HOST` (پیش‌فرض 127.0.0.1)، `CRM_DB` (مسیر فایل دیتابیس)، `CRM_SECURE_COOKIE=1` (پشت HTTPS).
> برای انتشار روی اینترنت، حتماً پشت یک reverse proxy با HTTPS قرار دهید.

## امکانات
| ماژول | توضیح |
|---|---|
| داشبورد | پایپ‌لاین باز، پیش‌بینی وزنی، فروش ماه، نرخ موفقیت، قیف فروش، نمودار ماهانه، وظایف معوق، معاملات نزدیک به بسته‌شدن |
| معاملات | نمای کانبان (کشیدن‌ورها یا انتخاب مرحله)، فهرست، اقلام معامله (جمع خودکار)، ثبت دلیل «ازدست‌رفته» |
| سرنخ‌ها | وضعیت و امتیاز، **تبدیل به مخاطب + شرکت + معامله** در یک تراکنش |
| مخاطبین / شرکت‌ها | جست‌وجو، فیلتر، مرتب‌سازی، صفحه‌بندی، صفحه‌ی ۳۶۰ درجه با تایم‌لاین |
| فعالیت‌ها | یادداشت، تماس، جلسه، ایمیل + رویدادهای خودکار سیستم (تغییر مرحله/وضعیت) |
| وظایف | موعد شمسی، اولویت، مرتبط با مخاطب/شرکت/معامله/سرنخ |
| محصولات | کاتالوگ (مدیریت: مدیر فروش به بالا) |
| گزارش تیم | عملکرد هر کارشناس (مدیر فروش به بالا) |
| کاربران و ممیزی | مدیریت کاربران/نقش‌ها و گزارش رویدادها (مدیر سیستم) |
| خروجی CSV | مدیر فروش به بالا؛ محافظت در برابر CSV-injection |

## نقش‌ها
- **کارشناس فروش**: فقط رکوردهای خودش (مخاطب، شرکت، سرنخ، معامله، وظایف خودش)؛ امکان حذف مخاطب/معامله ندارد.
- **مدیر فروش**: همه‌ی داده‌ها، حذف، خروجی CSV، گزارش تیم، محصولات.
- **مدیر سیستم**: همه‌ی موارد + کاربران + گزارش رویدادها.

## معماری
```
src/db.js         اسکیما SQLite + تراکنش
src/auth.js       scrypt، نشست‌های سمت سرور (توکن هش‌شده)، محدودسازی ورود
src/resources.js  تعریف اعلامی موجودیت‌ها + موتور CRUD (اعتبارسنجی، دسترسی، جست‌وجو)، تبدیل سرنخ
src/server.js     مسیرها، داشبورد، فایل ایستا، هدرهای امنیتی
src/seed.js       داده‌ی نمونه
public/           SPA فارسی (app.js, jalali.js, style.css)
test/             تست API (node:test) و تطبیق ۳۰ ساله‌ی تقویم شمسی با Intl
```
امنیت: گذرواژه با scrypt، کوکی HttpOnly+SameSite=Strict، هدر `X-Requested-With` علیه CSRF، پرس‌وجوی پارامتری و فهرست سفید ستون‌های مرتب‌سازی (ضد SQL-injection)، escape کامل خروجی HTML (ضد XSS)، CSP، ابطال نشست با غیرفعال‌سازی کاربر/تغییر گذرواژه.

## محدودیت‌ها / فرض‌ها
- واحد پول پیش‌فرض «تومان» است (ثابت `CURRENCY` در `public/app.js`).
- فرم‌ها تاریخ شمسی (`۱۴۰۵/۰۸/۲۱`) می‌گیرند و در دیتابیس به ISO میلادی ذخیره می‌شود.
- هنوز پیاده نشده: ایمیل/پیامک خودکار، ایمپورت CSV، فایل پیوست، ایزوله‌سازی چندسازمانی (multi-tenant).
