# راهنمای مرحله‌به‌مرحله: اجرای MANA روی سه گوشی

**چرا سرور HTTPS لازم است؟** نصب به‌صورت برنامه، اعلان وقتی برنامه بسته است و میکروفون فقط روی آدرس `https://` کار می‌کنند. شبکه‌ی خانگی (`http://192.168...`) برای این کارها کافی نیست.

## مرحله ۱ — خرید (یک‌بار، حدود ۱۵ تا ۲۵ دقیقه)
1. **دامنه**: مثلاً `bk-family.com` (حدود ۱۰ تا ۱۵ دلار در سال) از Namecheap/Porkbun/…
2. **سرور مجازی (VPS)**: اوبونتو ۲۴.۰۴، حداقل ۲ گیگ رم و ۲۰ گیگ دیسک (مثل Hetzner، DigitalOcean، Contabo). مکان سرور را **اروپا** انتخاب کنید.
3. در تنظیمات DNS دامنه یک رکورد `A` بسازید: نام `@` ← آی‌پی سرور. (تا ۳۰ دقیقه طول می‌کشد.)

## مرحله ۲ — آماده‌سازی سرور
از ترمینال کامپیوتر (ویندوز: PowerShell) وصل شوید: `ssh root@IP_SERVER`
```bash
apt update && apt install -y git docker.io docker-compose-v2
git clone -b ccr-e1b3dc84-iv05g9 https://github.com/manamoghadam-coder/Sarina-Earth-Animation.git
cd Sarina-Earth-Animation/mana/deploy
```
(مخزن خصوصی است: هنگام clone نام کاربری GitHub و یک Personal Access Token با دسترسی خواندن می‌خواهد.)

## مرحله ۳ — تنظیم اسرار
```bash
cp env.example .env
# سه رمز تصادفی و کلیدهای اعلان:
openssl rand -base64 24   # سه بار؛ برای PG_ADMIN_PASSWORD, OWNER_DB_PASSWORD, APP_DB_PASSWORD
docker run --rm node:22-slim npx -y web-push generate-vapid-keys   # VAPID_PUBLIC_KEY / PRIVATE_KEY
nano .env                 # DOMAIN و مقدارها را بنویسید؛ VAPID_SUBJECT=mailto:ایمیل-شما
```
`.env` را به هیچ‌کس ندهید.

## مرحله ۴ — راه‌اندازی
```bash
docker compose up -d --build
docker compose logs -f mana        # باید «MANA listening on :8080» ببینید (Ctrl+C برای خروج)
docker compose exec mana npx tsx scripts/seed.ts   # ساخت سه حساب؛ رمزها را همین‌جا یادداشت کنید (فقط یک‌بار چاپ می‌شود)
```
در مرورگر `https://دامنه‌ی-شما` را باز کنید؛ باید صفحه‌ی ورود با لوگوی BK ببینید و با `mana` وارد شوید.

## مرحله ۵ — هر گوشی (اندروید، Chrome)
1. Chrome را باز کنید و آدرس سایت را بزنید.
2. وارد حساب همان فرد شوید: گوشی شما ← `mana`، گوشی سارینا ← `sarina`، گوشی سامان ← `saman`. (رمز بچه‌ها را می‌توانید از «خانواده ← اعلان‌ها و تنظیمات» ساده‌تر کنید؛ حداقل ۸ نویسه.)
3. منوی ⋮ ← **Install app / افزودن به صفحه‌ی اصلی**. آیکون BK روی صفحه‌ی گوشی می‌نشیند.
4. از روی آیکون باز کنید. در صفحه‌ی اصلی (کودک) یا «تنظیمات» (شما) روی **«روشن کردن اعلان روی این دستگاه»** بزنید و **Allow** کنید.
5. **صدای فارسی**: تنظیمات گوشی ← Google ← Text-to-speech output ← موتور Google ← زبان **فارسی** و دانلود داده‌ی صدا. سپس در MANA «🔈 آزمایش صدا» را بزنید.
6. **میکروفون**: اولین بار که «دستیار من» را می‌زنید Allow کنید.
7. **باتری**: تنظیمات ← Apps ← Chrome ← Battery ← **Unrestricted**؛ تا اعلان‌ها دیر نرسند.

آیفون: iOS ۱۶.۴ یا بالاتر، فقط با **Safari ← Share ← Add to Home Screen** و باز کردن از آیکون؛ تشخیص گفتار فارسی روی آیفون محدودتر است.

> **گوشی بچه‌ها:** هر کودک با حساب خودش روی گوشی خودش وارد شود (مرحله ۵). مانا اعلان و میکروفون را روی گوشی او روشن کند، رمز را فقط به خود او بدهد و ساعت مرور شبانه را قبل از «ساعت سکوت» بگذارد.

## مرحله ۶ — آزمون
1. از گوشی شما: **خانواده ← سامان ← اعلان‌ها و تنظیمات ← ارسال اعلان آزمایشی** (برنامه‌ی گوشی سامان را ببندید). تا ۳۰ ثانیه اعلان می‌رسد.
2. در همان صفحه‌ی «تاریخچه‌ی اعلان‌ها» کنار هر اعلان `sent:1` یعنی پوش رفته؛ `no_subscription` یعنی روی آن گوشی اعلان روشن نشده؛ `no_vapid_keys` یعنی کلیدها در `.env` نیست.
3. فعالیتی با ساعت چند دقیقه‌ی بعد بسازید و ببینید در زمان خودش می‌آید.

## مرحله ۷ — بعد از آزمون
- داده‌ی «نمونه» را از برنامه حذف کنید و ساعت‌های برنامه‌ی سارینا/سامان را اصلاح کنید.
- رمزها را عوض کنید. عکس‌ها را از «خانواده ← تصاویر» بارگذاری کنید.
- پشتیبان: سرویس `backup` در compose هر شب حدود ساعت ۳ یک dump و نسخه‌ی فایل‌ها در volume `backups` می‌گذارد (۳۰ روز). حتماً یک نسخه را بیرون سرور نگه دارید و **تست بازیابی** را طبق `docs/BACKUP.md` یک‌بار انجام دهید. دفترچه‌ها، پیام‌ها و عکس‌های خانواده در این نسخه‌ها هستند؛ آن‌ها را خصوصی نگه دارید.
- به‌روزرسانی: `git pull && docker compose up -d --build`.

## نکته‌ی مهم درباره‌ی ایران
اعلان پوش روی اندروید از سرویس Google (FCM) عبور می‌کند. اگر گوشی‌ها در ایران بدون فیلترشکن به آن دسترسی ندارند، پوش با بسته بودن برنامه ممکن است نرسد؛ اعلان درون‌برنامه‌ای (وقتی برنامه باز است) در هر حال کار می‌کند. این را در مرحله‌ی ۶ همان روز اول بسنجید. دسترسی به خود سایت از ایران هم به مکان سرور و فیلترینگ بستگی دارد.
